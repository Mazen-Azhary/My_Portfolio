Projects

Production-grade Weather Monitoring System ☁️📊

As part of the "Designing Data-Intensive Applications" course, I collaborated with a team to build a highly scalable weather monitoring system handling 10,000+ readings/sec with zero data loss. The system uses Kafka for stream processing with features like rain alerts (humidity > 70%), idempotent receivers to discard duplicates, dead letter channels for failed messages, and durable subscribers for guaranteed delivery. We implemented a Bitcask storage engine (3k writes/sec, 22k reads/sec) and deployed the entire system on Kubernetes with Elasticsearch and Kibana for monitoring. GitHub Repo
